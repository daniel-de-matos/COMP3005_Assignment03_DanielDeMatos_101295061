1. Project Overview
This project implements a Student Database Management System using Python and PostgreSQL. The application connects to a PostgreSQL database and allows users to perform the four fundamental CRUD (Create, Read, Update, Delete) operations on student records. The application was developed as part of a database interaction and application programming assignment. It uses the psycopg library to establish a connection between Python and PostgreSQL and provides a menu-driven interface for managing student information.

Application Features
The application supports the following operations:
	Create: Add new student records to the database.
	Read: Retrieve and display all existing student records.
	Update: Modify the email address of an existing student.
	Delete: Remove a student record from the database.

4. Database Setup
Step 1: Create the PostgreSQL Database
	Open pgAdmin 4 and create a new database called:
		student_database

Step 2: Create the Students Table
	Open the Query Tool in pgAdmin 4 while connected to student_database and execute the following SQL statement:

	CREATE TABLE IF NOT EXISTS students (
    		student_id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    		first_name TEXT NOT NULL,
    		last_name TEXT NOT NULL,
    		email TEXT NOT NULL UNIQUE,
    		enrollment_date DATE
	);

Step 3: Insert Initial Student Records
	Execute the following SQL statement to populate the database with the initial student records:

	INSERT INTO students (
    		first_name,
    		last_name,
    		email,
    		enrollment_date
	)
	VALUES
    		('John', 'Doe', 'john.doe@example.com', '2023-09-01'),
    		('Jane', 'Smith', 'jane.smith@example.com', '2023-09-01'),
    		('Jim', 'Beam', 'jim.beam@example.com', '2023-09-02')
	ON CONFLICT (email) DO NOTHING;

Step 4: Verify the Database
	To verify that the records were successfully inserted, execute:
		SELECT * FROM students;

5. Application Functions
The application implements four primary functions corresponding to the CRUD operations.

1. getAllStudents() — Read
	Retrieves all student records from the PostgreSQL database.
	The function executes a SELECT query to retrieve student information, ordering the results by student ID.
	The retrieved records are displayed in the terminal, including: Student ID, First Name, Last Name, Email, and Enrollment Date
	If the database does not contain any records, the application displays an appropriate message.

2. addStudent(first_name, last_name, email, enrollment_date) — Create
	Allows users to insert a new student into the database.
	The user is prompted to provide:
		First Name
		Last Name
		Email
		Enrollment Date
	The student ID is automatically generated by PostgreSQL using the identity column. The function also includes error handling for invalid dates and duplicate 
	email addresses.

3. updateStudentEmail(student_id, new_email) — Update
	Allows users to update the email address associated with an existing student.
	The user provides the student's ID and the new email address.
	The function executes an UPDATE statement using the specified student ID. It also checks whether a matching student was found and handles duplicate email addresses.

4. deleteStudent(student_id) — Delete
	Allows users to delete an existing student record.
	The user provides the student ID of the record they wish to remove.
	The function executes a DELETE statement and checks whether the requested student was successfully deleted.
	If no matching student is found, the application displays an appropriate message.
